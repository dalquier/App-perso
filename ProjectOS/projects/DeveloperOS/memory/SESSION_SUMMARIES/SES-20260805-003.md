## Décisions

- Le module appartient à DeveloperOS.
- Deux canaux d’exécution sont retenus : `chatgpt_plus_manual` et `openai_api`.
- Un run hybride est dérivé de la combinaison des canaux et ne constitue pas un troisième canal.
- Le canal ChatGPT Plus repose sur un copier-coller manuel explicite, sans extraction automatique.
- Les prompts fils sont nommés `<nom exact du prompt maître> — <numéro>`.
- La séquence est générée à partir de l’ordre du tableau `jobs`, puis figée dans `run-plan.json` ; elle n’est pas fournie dans l’entrée V1.
- JSON est le format canonique V1.
- Les missions indépendantes peuvent être exécutées en parallèle dans la limite d’une concurrence configurée.
- Les résultats des dépendances sont injectés de manière déterministe dans les prompts aval.
- Les résultats des deux canaux convergent vers un même contrat avant synthèse maître.
- Le secret API reste exclusivement côté serveur.
- `CO-BUILD-00` doit figer les contrats avant toute parallélisation des développements.
