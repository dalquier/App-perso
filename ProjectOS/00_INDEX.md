# ProjectOS — Index canonique

## Autorité

Ce dossier est la référence commune de tous les projets personnels. GitHub `dalquier/App-perso`, branche `main`, est la source de vérité.

## Ordre de priorité

1. instruction explicite de Damien dans la conversation active ;
2. manifeste du projet concerné ;
3. règles permanentes de ProjectOS ;
4. ADR et décisions versionnées ;
5. documentation collaborative explicitement référencée sur Google Drive ;
6. copie locale iCloud ;
7. historique conversationnel.

## Références transverses

- `core/KERNEL.md` : séquence de décision obligatoire.
- `standards/QUALITY_UX_SECURITY.md` : qualité, tests, UX iPhone et sécurité.
- `standards/TOOLS_AND_STORAGE.md` : rôle de chaque application et stockage.
- `prompts/MASTER_PROJECT_PROMPT.md` : prompt remplaçant le GPT.
- `prompts/ACTION_PROMPTS.md` : commandes courtes pour les actions récurrentes.
- `templates/PROJECT_MANIFEST.md` : manifeste obligatoire de chaque projet.

## Références propres aux projets

Chaque projet possède son propre dossier sous `ProjectOS/projects/<projet>/` ou dans son dépôt dédié. Les documents Équilibre, TCC Budy et Guide Pyto ne deviennent pas des règles transverses : ils restent rattachés à leur projet et sont seulement indexés ici lorsqu’ils sont migrés.

## Stockages

- GitHub : code, règles, manifests, ADR et documentation versionnée.
- Working Copy : copie Git locale sur iPhone.
- iCloud Drive : fichiers locaux, échanges Pyto et données non versionnées.
- Google Drive : documents collaboratifs et sauvegardes horodatées.

Une sauvegarde Drive n’est jamais une source de vérité.
